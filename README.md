# Log Analysis with SIEM – TryHackMe Write-Up

This repository contains my write-up for the TryHackMe room **Log Analysis with SIEM**.

The room focused on using Splunk to analyse and correlate logs from different sources, including Windows, Linux, and web application logs. The investigation covered suspicious network connections, process activity, scheduled task persistence, Linux account creation, SSH login activity, cron-based persistence, and WordPress brute-force activity.

## Skills Practised

- SIEM log analysis
- Splunk searching and filtering
- Windows Sysmon investigation
- Linux `auth.log` and `syslog` analysis
- Web access log analysis
- Event correlation
- Suspicious process investigation
- Persistence detection
- Brute-force activity identification
